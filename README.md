# OMOLOLU HOSPITAL

Official website project for OMOLOLU HOSPITAL.

## Stack

- Next.js
- React
- TypeScript
- Vercel deployment

## Project phases

### Phase 1 — Public Website
Hospital information, doctor profile, services, facilities, opening hours, contact details, location, gallery, health information, announcements, FAQ and appointment/enquiry access.

### Phase 2 — Private EMR
A separate authenticated staff area for authorized hospital personnel. Patients will not have access to the EMR. Official patient identity will be based on hospital-issued registration/card information.

## Development

```bash
npm install
npm run dev
```

Then open http://localhost:3000.

## Deployment

The project is designed for deployment on Vercel. Connect this repository to a Vercel project and deploy the `main` branch.
